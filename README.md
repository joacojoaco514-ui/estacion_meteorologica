## 📂 Estructura del Repositorio

A continuación se detalla la organización de los componentes del proyecto:

* 📁 **`análisis_ipynb/`** → Prototipado, experimentación y limpieza de datos en Google Colab.
* 📁 **`arduino_ino/`** → Código fuente (`.ino`) para el firmware del Arduino UNO R3.
* 📁 **`panel_pbix/`** → Reportes, tableros dinámicos y métricas visuales en Power BI.
* 📁 **`base_de_datos_sql/`** → Scripts y diseño de la estructura relacional en MySQL Workbench.
* 📁 **`aplicación Python/`** → Aplicación de escritorio desarrollada en Python bajo el paradigma de POO.
* 📁 **`docs/ SIMULACROS_BRD/`** → Documentación técnica, esquemas de circuitos y simulaciones.
* 📄 **`LÉAME.md`** → Guía principal del proyecto (este archivo).

## 🛠️ Tecnologías Utilizadas

### **Programación y Firmware**
* **🤖 Arduino** | Implementación de firmware y control de sensores en hardware real (Arduino UNO R3).
* **🐍 Python** | Desarrollo de la lógica principal, interfaz de escritorio (POO) y servicios de conectividad.

### **Datos y Analítica**
* **🗄️ MySQL** | Diseño, gestión y almacenamiento persistente de las lecturas climáticas.
* **📓 Jupyter Notebooks** | Procesamiento, análisis exploratorio y limpieza de datos.
* **📊 Power BI** | Creación de dashboards interactivos para la visualización de variables meteorológicas.

### **Gestión de Proyecto**
* **🌿 Git & GitHub** | Control de versiones y alojamiento del código fuente.
* **📄 Markdown** | Documentación técnica y especificaciones del sistema.
